# Démonstration en trois minutes

Préciser d’emblée : **projet pédagogique assisté par IA, données fictives, aucune affiliation officielle au BVG Mali**. Il sert à discuter du code et ne constitue pas une expérience professionnelle passée.

1. Registre : rechercher « beta », combiner les filtres « Nouvelle » et « Demandes », puis effacer les filtres.
2. Formulaire : soumettre à vide, lire les erreurs, puis créer un exemple entièrement inventé avec une échéance future.
3. Historique : démarrer le dossier et le soumettre avec des commentaires ; constater que le rédacteur simulé ne clôture pas. Passer au superviseur simulé et clôturer.
4. Lecteur : montrer la création désactivée ; expliquer que cette simulation n’authentifie personne.
5. Architecture : l’aperçu public utilise seulement le navigateur. L’API C# a été testée localement en mémoire ; les scripts SQL Server sont non exécutés et non raccordés.

Les changements de la démo restent sur l’appareil du visiteur. Effacer uniquement la clé repere-pedagogique-v1 dans le stockage local de cette origine pour retrouver les exemples initiaux. Ne saisir aucune information réelle.

Avant entretien, refaire une petite fonctionnalité sans assistance, expliquer une validation et une réponse 409, puis préciser ce qui reste à apprendre. Les résultats de tests ne prouvent pas à eux seuls la maîtrise du candidat.
