# Périmètre public de Repère

Cette copie indépendante anonymisée est destinée à un dépôt public séparé et à GitHub Pages. Seuls les fichiers de cet exercice sont inclus. Aucun portfolio, document de candidature privé ou autre application n’est inclus ou modifié.

## Aperçu public

Interface React/TypeScript compilée en mode navigateur, exemples fictifs et stockage local par visiteur. Pas d’API hébergée, pas de base SQL, pas d’authentification réelle. Les mentions assisté par IA, rôles simulés et absence d’affiliation au BVG Mali restent visibles.

## Sources publiques

Sources React/TypeScript et C#, tests, jeu fictif, scripts SQL non exécutés et non raccordés, verrou de dépendances, documentation anonymisée, captures renouvelées et synthèse des vérifications. Les traces brutes, chemins locaux, coordonnées, archives privées, secrets, certificats, outils et dépendances installées sont exclus.

## Hébergement

GitHub Pages est disponible gratuitement pour les dépôts publics avec GitHub Free : [documentation officielle](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages). La branche gh-pages contient seulement le contenu compilé de preview/ à sa racine et un fichier .nojekyll. Aucun workflow personnalisé, jeton personnel, secret ou domaine payant n’est nécessaire. Le fournisseur gère son mécanisme interne de publication.

Le dépôt et l’URL sont publics, ainsi que le nom public du compte GitHub. Les commits utilisent une adresse GitHub noreply. Aucune adresse privée n’est incluse dans leur identité.

L’API C# demeure locale en mémoire. SQL Server est fourni comme code à étudier, sans résultat d’exécution revendiqué. Cette publication ne transforme pas l’exercice assisté par IA en expérience professionnelle antérieure.
